# Fixtures

Where the files under `fixtures/seed/` and `fixtures/ui/` come from. Every fixture file has one row; the repository test `Every_fixture_file_is_listed_in_fixtures_readme` fails when a file has no row or a row has no origin.

Rules (legal guardrails spec, section 5): seed files hold functional metadata only (logical and schema names, type codes, well-known GUIDs, option values, catalogs). Labels are short names; no descriptive text is copied from Microsoft documentation. The origin is a Microsoft Learn page (public documentation, paraphrased), "observed on a licensed Dataverse environment", or, for files with no Dataverse content, the repository itself. Where the repository history and specs do not say, the origin is `origin to be confirmed`; do not guess one.

About the seed tables: the system seed is hand-written. The tables were defined in the commits of 2026-11-07 and 2026-11-08 and extended by later plans, with logical and schema names, types, object type codes and option values taken from the Microsoft Learn table reference, and only the columns xrmverse uses. No metadata export of a Dataverse environment is in the repository. The maintainers confirmed these origins on 2026-11-20.
